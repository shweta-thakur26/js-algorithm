2. push() and pop()

push()

Adds an element to the END of an array.

array.push(100);

pop()

Removes the LAST element from an array.

array.pop();

3. shift() and unshift()

shift()

Removes the first element.

array.shift();

unshift()

Adds an element to the beginning.

array.unshift(5);

4. for Loop

A loop allows us to execute the same logic for every element.

for (let i = 0; i < array.length; i++) { console.log(array[i]); }

5. map()

map() creates a NEW array by transforming every element.

const result = array.map(num => num * 2);

6. filter()

filter() creates a new array containing only elements that satisfy a condition.

const result = array.filter(num => num > 20);

7. reduce()

reduce() combines all elements into one final value.

const sum = array.reduce((total, num) => { return total + num; }, 0);

8. find()

Finds the first element that satisfies a condition.

const result = array.find(num => num > 20);

9. some() vs every()

some()

Returns true if at least one element passes the condition.

array.some(num => num > 40);

every()

Returns true only if all elements pass the condition.

array.every(num => num > 0);

10. includes()

Checks whether an array contains a particular value.

array.includes(30);

11. indexOf()

Finds the index/position of an element.

array.indexOf(30);

12. sort()

Sort numbers in ascending order.

array.sort((a, b) => a - b);

13. Spread Operator (...)

Spread allows us to copy or combine arrays.

const copy = [...array]; const combined = [...array, 100, 200];

14. Array Destructuring

Destructuring lets us extract values from an array into variables.

const [first, second, third] = array;
