2. push() and pop()

push()

Adds an element to the end of the array.

array.push(100);

pop()

Removes the last element from the array.

array.pop();

3. shift() and unshift()

shift()

Removes the first element.

array.shift();

unshift()

Adds an element at the beginning.

array.unshift(5);

4. for Loop

A loop helps you process each item in sequence.

for (let i = 0; i < array.length; i++) { console.log(array[i]); }

5. map()

map() creates a new array by transforming every value.

const result = array.map(num => num * 2);

6. filter()

filter() keeps only elements matching a condition.

const result = array.filter(num => num > 20);

7. reduce()

reduce() combines values into a single final result.

const sum = array.reduce((total, num) => total + num, 0);

8. find()

Finds the first element that satisfies a condition.

const result = array.find(num => num > 20);

9. some() vs every()

some()

Returns true if at least one value matches.

array.some(num => num > 40);

every()

Returns true only if all values match.

array.every(num => num > 0);

10. includes()

Checks whether a specific value exists in the array.

array.includes(30);

11. indexOf()

Finds the position of an element.

array.indexOf(30);

12. sort()

Sort array values in ascending or descending order.

array.sort((a, b) => a - b);

13. Spread Operator (...)

Use spread syntax to copy or combine arrays.

const copy = [...array]; const combined = [...array, 100, 200];

14. Array Destructuring

Extract values from an array in a clean, readable way.

const [first, second, third] = array;
